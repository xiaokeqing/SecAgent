# 防火墙、WAF、IDS/IPS 与 VPN 安全设备

> 安全服务工程师常接触四款主流设备：防火墙、VPN、WAF、IDS/IPS。理解工作原理、部署位置和日志特征，是安全设备运维、安全运营和告警研判的基础。

## 一、防火墙（Firewall）
### 原理
基于安全策略（五元组：源 IP、目的 IP、源端口、目的端口、协议）做访问控制，决定数据包放行/拒绝。下一代防火墙（NGFW）增加应用识别、用户、内容、入侵防御、VPN 等能力。
- **安全区域**：Untrust（外网）、DMZ（对外服务区）、Trust（内网）、Local，区域间配置策略，默认拒绝。
- **NAT**：源 NAT 让内网共享公网出口；目的 NAT/端口映射把外网访问映射到 DMZ 服务器。
- 状态检测：基于会话表跟踪连接状态。

### 部署
- 边界部署：外网—防火墙—DMZ/内网；
- 策略原则：最小权限、白名单、默认拒绝、定期清理冗余策略。

### 日志特征
- 允许/拒绝会话记录、NAT 转换、会话数；
- 研判：大量拒绝、异常外联（C2/矿池）、端口扫描、非预期开放端口。

## 二、WAF（Web 应用防火墙）
### 原理
工作在应用层（HTTP/HTTPS），基于规则、语义分析、模型、白名单识别并拦截 Web 攻击。
- 防护能力：SQL 注入、XSS、命令注入、文件上传、路径穿越、CC、扫描器、Bot 防护、敏感信息泄露、虚拟补丁。
- 部署模式：**透明/串联（阻断）**、**反向代理**、**旁路镜像（仅检测）**；策略可设阻断/观察/告警。

### 与传统防火墙区别
- 防火墙管"能不能连通"（网络层/端口）；
- WAF 管"请求内容是否恶意"（应用层），能解析 HTTP 参数、body、Cookie。

### 日志特征
- 命中规则 ID、攻击类型、请求 URL、payload、动作（拦截/放行）、源 IP；
- 研判：WAF 大量拦截说明被攻击；拦截后仍有 200 成功需关注绕过；WAF 不能替代代码修复。

### 局限与规避认知
- 绕过属于攻击技术，防御侧应做：规则持续更新、语义/模型检测、HTTPS 解密审计（合规前提）、结合代码修复，不能只靠 WAF。

## 三、IDS / IPS（入侵检测/防御系统）
### 区别
- **IDS（检测）**：旁路部署，镜像流量，**只检测告警**，不阻断；
- **IPS（防御）**：串联部署，**实时检测并阻断**，会引入时延和单点风险。

### 原理
- 基于**特征签名（Signature）**、协议异常、流量基线、行为分析识别入侵；
- 主机侧对应 HIDS（如 OSSEC、Wazuh），网络侧对应 NIDS/NIPS（如 Snort、Suricata、商业 IDP）。

### 日志与告警
- 事件名称、签名 ID、严重等级、源/目的 IP、五元组、协议、攻击方向；
- 研判：关联资产重要性、是否成功、有无后续行为（主机日志、Web 日志印证），区分真实攻击与误报。

## 四、VPN（远程/站点互联）
### 作用
在公网上建立加密隧道，用于远程办公接入（远程访问 VPN）或分支机构互联（站点到站点 VPN）。
- 常见技术：IPSec、SSL VPN、L2TP、GRE；
- 安全要点：多因素认证、强口令、最小权限、按用户/组授权、连接审计、及时回收账号；
- 风险：VPN 账号被爆破（弱口令）后可直接进入内网，是常见入口。

### 日志特征
- 登录成功/失败、来源 IP、账号、时间、断开原因；
- 研判：异地/异常时间登录、大量失败、VPN 登录后的横向活动。

## 五、设备协同与告警研判
典型攻击链中设备各司其职：
- 防火墙看连接与外联、NAT；
- WAF 看 Web 攻击；
- IDS/IPS 看漏洞利用与异常流量；
- VPN 看远程接入；
- 单点日志可能误报，需结合主机日志、Web 日志、威胁情报多源印证，形成攻击链（见 Kill Chain 与日志分析文章）。

## 六、设备运维要点
- 规则库/威胁库及时更新；
- 策略最小化、定期评审、配置备份；
- 日志统一接入 SIEM/日志平台，统一时间源（NTP）；
- 高可用、性能与误报率平衡；
- 对未接触的新设备，按"部署位置—工作层次—核心功能—日志字段—告警含义"的方法分析，可举一反三。

## 七、与项目关联
SecAgent 内置防火墙日志、安全告警（SSH 爆破、SQL 注入、Webshell、扫描）模拟数据，多 Agent 研判时会把设备告警与主机/Web 日志关联，正是安全运营平台（SOC/SIEM）对多设备日志做关联分析的缩影。
