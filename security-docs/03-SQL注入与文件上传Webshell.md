# SQL 注入、文件上传漏洞与 WebShell 攻防

## 一、SQL 注入（CWE-89，OWASP A03）

### 1. 原理
程序把用户输入直接拼接进 SQL 语句，攻击者通过单引号、UNION、布尔/时间盲注等改变语句语义，从而读取、篡改数据库甚至执行命令。

典型攻击载荷：
- 报错探测：`id=1'`
- 联合查询：`id=-1' UNION SELECT 1,user(),version() FROM information_schema.tables-- `
- 拖库特征：`information_schema`、`load_file`、`into outfile`
- 日志特征：`union select`、`sleep(5)`、`or 1=1`、`%27`、`%20or%20`

### 2. 危害
绕过登录、拖库（账号/密码/身份证）、写入 WebShell（高权限数据库）、数据篡改或删除。

### 3. 防御
- 优先使用**参数化查询 / 预编译（PreparedStatement）**，MyBatis 使用 `#{}` 而非 `${}`。
- 服务端输入校验，最小权限数据库账号（禁止 DBA/ FILE 权限）。
- 关闭报错回显，统一异常处理；敏感信息加密存储。
- 部署 WAF 规则（拦截 union select、information_schema），但 WAF 只是补充，不能替代代码修复。
- 定期用静态检测和漏扫发现注入点。

## 二、文件上传漏洞（CWE-434）

### 1. 原理
应用允许上传文件，但未严格校验类型、内容、路径，攻击者上传脚本文件（.php/.jsp/.asp），再通过 URL 访问执行，导致任意代码执行。

### 2. 常见绕过
- 改扩展名：`shell.php.jpg`、`x.asp;.jpg`（解析漏洞）
- 大小写、双写、特殊字符：`shell.PhP`、`shell.phtml`
- 伪造 Content-Type：`image/jpeg`
- 图片马：在真实图片头部后插入脚本
- 配合路径穿越上传到可执行目录

### 3. 防御
- 服务端白名单校验**扩展名**（取最后一个点，统一小写），并校验文件内容/魔术字节。
- 上传文件重命名（UUID 或净化后的名字），去除用户可控路径。
- 上传目录放在 Web 根之外或配置为**不可执行**，独立存储/CDN 域名。
- 限制文件大小、拒绝脚本类型、对返回内容做 Content-Disposition 附件处理。
- 上传后入库前做敏感信息扫描（密钥、私钥），防止敏感数据泄露。

## 三、WebShell 检测与处置

### 1. 什么是 WebShell
攻击者上传的网页脚本后门，一句话木马形如 `eval(request("cmd"))`，可执行命令、读写文件、连接数据库。

### 2. 检测特征
- 上传目录出现脚本文件（.asp/.php/.jsp），文件名含 `;`、双扩展名。
- 访问 URL 携带 `cmd=`、`eval`、`assert`、`base64_decode`、`system`、`whoami`。
- 主机出现 www-data/apache 用户执行 `bash -i`、`/dev/tcp/IP/端口` 反弹 shell。
- 新增计划任务、异常外联（C2 长连接）。

### 3. 应急处置
1. 立即隔离主机/封禁来源 IP（本系统研判报告中对应 103.146.184.77）。
2. 保留现场：Web/系统日志、内存、文件时间戳。
3. 清除 WebShell 及其持久化（crontab、ssh key、新增账号）。
4. 回溯攻击入口（上传点/注入点）并修复，从可信备份恢复。
5. 排查横向移动，重置凭据，观察是否再次复发。

## 四、IOC（失陷指标）记录规范
- 攻击源 IP、攻击时间、受影响资产 IP/域名。
- 恶意文件路径、URL、命令载荷、外联 C2 的 IP/端口。
- 攻击者账号、新增账号、计划任务、SSH key 指纹。
