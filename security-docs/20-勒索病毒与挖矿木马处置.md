# 勒索病毒与挖矿木马处置

## 一、勒索病毒
### 特征
- 文件被批量加密、扩展名被改（如 `.locked/.ryuk/.wannacry`），桌面留下勒索信（README）；
- 大量文件读写、磁盘 IO 飙升、共享目录被加密；
- 常通过 RDP 爆破、钓鱼、永恒之蓝（SMB）、弱口令、Web 漏洞进入。

### 处置
1. **立即断网**（拔网线/禁网卡），但先不要关机，保留内存；防止扩散到共享存储。
2. 隔离受感染主机，阻断与内网共享、备份服务器的连接。
3. 确定勒索家族与入口（日志、样本、勒索信），检查是否有内网横向。
4. **禁止在未确认前向加密文件写入**；优先从离线备份恢复。
5. 清理持久化（启动项、计划任务、服务、账号）后再恢复。
6. 修复入口（补丁、关闭 445 暴露、RDP 管控、改密）。
7. 按规定上报，不建议轻易支付赎金（不保证解密且违法风险）。

### 预防
- 3-2-1 备份（多份、离线、定期验证可恢复）；
- 及时打补丁（SMB 永恒之蓝）、最小权限、关闭不必要共享；
- 邮件网关、EDR、网络分段、RDP 不暴露公网。

## 二、挖矿木马
### 特征
- CPU/GPU 占用持续接近 100%，机器变卡、风扇狂转；
- 大量外连矿池地址（常见端口 3333、4444、5555、14444、stratum 协议）；
- 进程名伪装（`kdevtmpfsi`、`kinsing`、`xmrig`、系统名仿冒）；
- 常通过未授权访问（Redis、Docker API、Kubernetes）、Web 漏洞、弱口令、计划任务进入。

### 排查
1. `top`/任务管理器定位高 CPU 进程，记录 PID、路径、父进程。
2. `netstat -anp` / `netstat -ano` 查外连矿池 IP，匹配威胁情报。
3. 查持久化：`crontab -l`、`/etc/init.d`、`systemd`、Windows 计划任务、启动项。
4. 查容器环境（未授权 Docker API、K8s 容器里挖矿）。
5. 溯源入口：Web 日志、Redis 未授权、SSH 爆破、组件漏洞。

### 处置
1. 杀死进程并删除恶意程序，清理计划任务/服务/启动项。
2. 阻断矿池外连（防火墙/IPS），封禁相关 IOC。
3. 修复入口漏洞，关闭未授权服务、改密码、加认证。
4. 清理其他被横向感染的主机，升级补丁。

---

## 三、共同的研判要点
- 都要回答三个问题：**从哪进来、影响多大、是否横向**；
- 证据链：入口日志 → 落地文件/进程 → 持久化位置 → 外连 IOC → 受影响范围；
- 处置后必须修复根因，否则反复复发。
