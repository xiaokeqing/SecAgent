# Web 应用安全加固基线（Checklist）

> 用于安全开发生命周期（SDL）与上线前自查。本文给出的均为防御性配置与编码要求。

## 一、认证与授权
- [ ] 接口默认拒绝，必须显式授权；后台与高敏接口强制鉴权。
- [ ] 禁止匿名访问写操作（上传、删除、执行、查询他人数据）。
- [ ] 增加 Token/Session 校验，Token 足够长、可过期、可吊销；常量时间比较防时序侧信道。
- [ ] 登录、验证码、敏感接口加限流与失败锁定，防暴力破解与撞库。
- [ ] 服务端做越权校验（水平/垂直），不信任前端传来的用户 ID、会话 ID。
- [ ] 会话设置 TTL 与数量上限，防止内存无限增长；多租户会话与用户绑定。

## 二、输入校验与文件处理
- [ ] 所有外部输入白名单校验（类型、长度、范围、字符集）。
- [ ] 文件上传：扩展名白名单、内容校验、重命名、上传目录不可执行、路径穿越防护。
- [ ] 数据库访问统一预编译/参数化（MyBatis 用 `#{}`）。
- [ ] 命令执行禁止拼接输入，必须使用参数化 API；关闭不必要的系统命令调用。
- [ ] 输出编码（HTML/JS/URL 上下文），防 XSS。

## 三、安全配置
- [ ] CORS 不使用 `*`，按最小必要配置来源；不允许任意来源携带凭据。
- [ ] 关闭调试模式、目录列举、默认账号、示例应用。
- [ ] 错误信息统一处理，不向客户端返回堆栈、内部路径、SQL、框架版本。
- [ ] 隐藏/管理 Actuator 等敏感端点，必要时加鉴权。
- [ ] 合理设置上传大小、请求体大小、超时、连接数。
- [ ] 安全响应头：Content-Security-Policy、X-Content-Type-Options、X-Frame-Options、HSTS。

## 四、敏感信息与密钥
- [ ] 密钥、口令、Token 不硬编码进代码或文档，通过环境变量/密钥管理服务注入。
- [ ] 数据入库前做敏感信息扫描（DLP），防止私钥、AccessKey、口令进入知识库/日志。
- [ ] 日志脱敏，不记录密码、Token、身份证、银行卡。
- [ ] 及时轮换泄露凭据；`.gitignore` 排除配置与密钥文件。

## 五、监控与日志（对应 OWASP A09）
- [ ] 关键事件留痕：登录、上传、权限变更、异常 4xx/5xx、安全告警。
- [ ] 接入 WAF/IDS/HIDS 与集中日志，建立告警与应急响应流程。
- [ ] 告警与日志可相互印证：攻击源 IP、受影响资产、时间线、手法一致。
- [ ] 定期做漏洞扫描、依赖成分分析（SCA）、补丁更新。

## 六、最小权限与纵深防御
- [ ] 中间件、数据库、服务账号最小权限；数据库账号不要 FILE/管理员权限。
- [ ] 网络分区，数据库、内部服务不直接暴露公网；端口最小化。
- [ ] 主机基线：禁 root 登录、密钥登录、fail2ban、HIDS、及时打补丁。
- [ ] 数据加密传输（TLS）与敏感数据加密存储；定期备份并验证可恢复。
