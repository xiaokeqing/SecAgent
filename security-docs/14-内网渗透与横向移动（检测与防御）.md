# 内网渗透与横向移动（检测与防御视角）

> 本篇从蓝队/防御视角梳理内网攻击的概念、检测点与防护手段，用于理解失陷后的扩散路径与防护，不提供可直接复用的攻击命令或绕过工具。

## 一、为什么会有内网横向
边界被突破（Webshell、弱口令、钓鱼、漏洞）后，攻击者从一台"跳板机"向内部网络扩张，目标是更多主机、数据库、域控、核心系统。内网默认信任度高、监控弱，是损失放大的关键阶段。

## 二、核心概念（理解即可）
- **工作组 / 域（Active Directory）**：域控（DC）统一管理账号与策略，控制域控通常意味着控制整个域。
- **信任关系**：机器间、域间、服务间的隐式信任（如数据库信任应用服务器、共享文件服务器）。
- **凭证**：明文密码、NTLM Hash、Kerberos 票据、登录会话。
- **横向移动**：利用合法管理协议和凭证在机器间跳转（如 SMB/RDP/WMI/WinRM/PSRemoting）。
- **隧道/代理**：在已控主机上转发流量，访问内网或绕过边界。

## 三、攻击者通常做什么（用于检测）
1. 内网发现：主机、网段、端口、存活主机、域信息、管理员信息；
2. 凭据收集：读取本机凭据、浏览器密码、配置文件、数据库连接串；
3. 横向移动：用管理协议/远程服务登录其他主机、投放载荷；
4. 权限提升与域内控制：寻找高权限服务、服务账号、域控；
5. 数据收集与外传：定位共享/数据库，打包外发。

## 四、检测点（蓝队重点）
- **Windows 事件**：
  - 4624（登录）关注类型 3 网络登录、类型 10 RDP；
  - 4627（Kerberos 认证）、4768/4769（票据请求）、4720/4732（账号与组变更）；
  - 5140（网络共享访问）、5145（共享访问细节）、4672（特权使用）；
  - 4698/4697（计划任务/服务创建）。
- **异常特征**：
  - 一台主机在短时间内用同一账号登录多台机器（横向扫描特征）；
  - 普通账号登录服务器、域控、数据库；
  - 非工作时间的 SMB/RDP/WMI/WinRM 连接；
  - 管理工具（远程执行、服务创建）在应用服务器上被使用；
  - 内网大量探测连接（445/135/3389）、异常端口转发。
- **主机侧**：异常进程（远程执行、PowerShell、凭据转储工具的特征行为）、新增服务/任务。

## 五、防御
1. **网络分段与零信任**：按业务划区，最小化开放端口（不必全网通 445/3389），服务器区与办公区隔离。
2. **最小权限与特权管理（PAM）**：
   - 普通用户与管理员分离，禁止管理员日常上网；
   - 服务账号最小化、不跨机器复用；
   - 用堡垒机/跳板机管理，启用 MFA；
   - 高权限账号不登普通终端。
3. **保护凭证**：
   - 管理员密码不同机复用、LAPS 本地管理员密码随机化；
   - 关闭/限制高风险协议（如 NTLM、SMBv1）、启用受保护用户组；
   - 对域控做重点监控与加固。
4. **打补丁、关默认共享、禁弱口令**，收敛管理面。
5. **监测与狩猎**：部署 EDR、日志集中（SIEM）、按 ATT&CK 编写检测规则，对横向移动做关联分析。

## 六、与项目/研判的关系
多 Agent 研判中，当某主机对外连接 C2、或出现 Webshell 后，需要结合内网日志判断"是否横向"：该主机是否扫描/登录了其他主机、是否触碰域控/数据库。知识库的 Kill Chain、事件分级与日志分析文章共同支撑"影响面评估"，输出隔离、封禁、横向排查与分段加固建议。
