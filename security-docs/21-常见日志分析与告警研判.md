# 常见日志分析与告警研判

## 一、Linux 主机日志（/var/log）
- `auth.log` / `secure`：认证日志。重点看 `Failed password`（爆破）、`Accepted password`（登录成功）、`sudo`、`session opened`、用户增删。
- `syslog` / `messages`：系统事件、计划任务、服务启停。
- `last`、`lastb`：成功/失败登录历史；`who`、`w`：当前登录。
- `cron`：计划任务（挖矿、后门常写 cron）。
- 研判：大量 Failed 后出现 Accepted（爆破成功）；异常来源 IP、非工作时间登录、root 登录。

## 二、Web 访问日志（Nginx/Apache）
- Nginx：`access.log`、`error.log`；Apache：`access_log`、`error_log`。
- 字段：源 IP、时间、请求方法、URL、状态码、响应大小、User-Agent。
- 攻击特征：
  - SQL 注入：`union select`、`or 1=1`、`sleep`、`--`、`information_schema`；
  - XSS：`<script>`、`onerror`、`javascript:`；
  - 文件上传：POST 到上传接口、文件名含 `.jsp/.php`；
  - 路径穿越：`../`、`%2e%2e`、`/etc/passwd`；
  - 扫描：大量 404、连续探测路径、单一 UA、扫描器特征；
  - Webshell：对固定可疑文件的 POST、命令执行参数。
- 状态码研判：200 且 payload 成功、403 被拦、500 报错。

## 三、Windows 事件日志
- 安全日志：4624 登录成功、4625 失败、4672 特权登录、4720 建账号、4732 加入组；
- 登录类型：2 本地、3 网络、10 RDP、5 服务；
- System、Application 日志：服务安装、异常崩溃。

## 四、防火墙/网络设备日志
- 允许/拒绝记录、NAT、会话；
- 重点：异常外连（C2、矿池）、端口扫描、大量 SYN、异常源/目的端口；
- 结合威胁情报判断外连 IP 是否为恶意地址。

## 五、多源日志关联（研判核心）
单点告警可能误报，必须**跨源交叉印证**：
- 告警说某 IP 对 SSH 爆破 → 去 auth.log 找 Failed/Accepted；
- 同一 IP 出现在 Web 日志（上传 Webshell）→ 去主机日志找命令执行；
- 防火墙日志看到该主机对陌生 IP 的外连 → 确认 C2。
- 时间线对齐：攻击源 IP、受影响资产、时间、手法、成功与否。

## 六、研判结论应包含
- 告警是否真实（真阳性/误报）；
- 攻击链：入口、利用、权限、横向、外连；
- 影响面与严重等级；
- IOC（IP、域名、URL、文件哈希、攻击特征）；
- 处置建议（封堵、隔离、清除、加固、溯源）。

## 七、与项目 mock 数据对应
内置 4 类安全告警与日志：SSH 暴力破解、Web SQL 注入、Webshell 检测、目录扫描；研判时主机认证日志、Web 访问日志、系统事件、防火墙日志中的同一攻击源 IP 会互相印证，最终还原完整攻击链。
