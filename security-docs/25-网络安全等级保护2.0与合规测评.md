# 网络安全等级保护 2.0 与合规测评

> 等保测评（等保测试员）是安全服务/安全咨询岗位的常见方向。本文梳理等级保护 2.0 的体系、流程、控制点和测评要点。

## 一、什么是等级保护
网络安全等级保护（等保）是中国网络安全的基础性制度，依据《网络安全法》要求，对网络/信息系统按重要程度分等级实施不同强度的安全保护。标准核心是 **GB/T 22239-2019《信息安全技术 网络安全等级保护基本要求》**（即"等保 2.0"）。

## 二、五个安全等级
- **一级（自主保护级）**：受到破坏后对公民、法人合法权益造成损害，不危害国家安全和社会秩序。
- **二级（指导保护级）**：对社会秩序和公共利益造成一定损害，不危害国家安全。
- **三级（监督保护级）**：对社会秩序和公共利益造成严重损害，或对国家安全造成损害（**最常见的重点级别，金融/政务/医疗等多为三级，每年至少一次测评**）。
- **四级（强制保护级）**：对社会秩序和公共利益造成特别严重损害，或对国家安全造成严重损害。
- **五级（专控保护级）**：对国家安全造成特别严重损害。

## 三、五个规定动作
1. **定级**：自主定级并组织专家评审，确定等级。
2. **备案**：二级以上到公安机关网安部门备案（一般 30 日内）。
3. **建设整改**：按对应等级要求做安全建设和整改。
4. **等级测评**：委托具备资质的测评机构开展等级测评（三级以上每年一次）。
5. **监督检查**：公安机关对运营使用单位进行监督检查。

## 四、安全通用要求（技术 + 管理）
等保 2.0 采用"一个中心，三重防护"技术框架。

**技术要求：**
- 安全物理环境（机房、门禁、消防、供电）；
- 安全通信网络（网络架构、通信传输、可信验证）；
- 安全区域边界（边界防护、访问控制、入侵防范、恶意代码、安全审计）；
- 安全计算环境（身份鉴别、访问控制、安全审计、入侵防范、恶意代码、数据完整性/保密性、数据备份恢复、剩余信息保护、个人信息保护）；
- **安全管理中心**（系统管理、审计管理、安全管理、集中管控）。

**管理要求：**
- 安全管理制度、安全管理机构、安全管理人员、安全建设管理、安全运维管理。

## 五、扩展要求
等保 2.0 相对 1.0 增加了对新形态的覆盖：
- **云计算**安全扩展要求；
- **移动互联**安全扩展要求；
- **物联网**安全扩展要求；
- **工业控制系统**安全扩展要求。

## 六、测评流程
1. 测评准备：确定对象、资料收集、编制测评方案；
2. 方案编制与确认；
3. 现场测评：
   - 访谈（人员）、文档检查（制度/记录）、配置核查（设备/主机）、工具测试（漏洞扫描、验证）；
   - 采用"单元测评 + 整体测评"，对控制点逐项判定符合/部分符合/不符合；
4. 结果分析与风险评价；
5. 输出《等级测评报告》，给出得分与结论（优/良/中/差），列出不符合项与整改建议；
6. 整改后复测。

## 七、常见控制点（三级示例）
- 身份鉴别：唯一性、复杂度、登录失败处理、双因素（三级重要系统/管理通道）；
- 访问控制：最小权限、默认拒绝、权限分离；
- 安全审计：日志覆盖、留存（一般不少于 6 个月）、审计员独立、防篡改；
- 入侵防范：补丁、最小化、关闭高危端口、部署防病毒/HIDS；
- 数据：传输/存储加密、备份、异地容灾；
- 边界：区域划分、防火墙、IPS、准入控制；
- 集中管控：统一日志、统一安全管理、时间同步。

## 八、与其他合规/工作的关系
- 与风险评估、渗透测试、代码审计、漏洞扫描互补：测评常包含这些技术手段；
- 行业还有 PCI-DSS（支付）、ISO 27001、数据安全法/个人信息保护法、关基保护（CIIP）等要求。

## 九、与项目/岗位关联
- 简历项目中"安全加固基线（路径穿越修复、鉴权、CORS、会话治理、日志审计、异常处理、敏感信息扫描）"对应等保"安全计算环境/安全审计"的多个控制点，可在面试中把项目加固与等保条款对应起来讲。
- 等保测试员偏文档与配置核查、流程规范，安全服务工程师则常承担建设整改、漏洞扫描、渗透测试与复测工作。
