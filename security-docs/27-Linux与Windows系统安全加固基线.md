# Linux 与 Windows 系统安全加固基线

> 安全运维服务工程师要能做系统级安全加固。本文给出 Linux 与 Windows 主机的加固基线清单（对应等保"安全计算环境"）。

## 一、通用加固原则
- 最小化：最小安装、最小服务、最小权限、最小开放端口；
- 纵深防御：边界 + 主机 + 应用 + 数据多层；
- 默认拒绝、白名单；
- 补丁、备份、日志、监控常态化。

## 二、Linux 加固基线

### 1. 账号与口令
- 禁用/锁定无用账号，删除默认/测试账号；
- 强口令策略（`/etc/login.defs`、`pam_pwquality`），长度、复杂度、有效期；
- 禁止 root 直接远程登录（`PermitRootLogin no`）；
- 限制 `su`/`sudo`，审计 sudoers；
- 密码错误锁定（`pam_faillock`）。

### 2. SSH 安全
- 禁用密码登录、改密钥登录（`PasswordAuthentication no`）；
- 修改默认端口（仅缓解，非根本）、限制来源 IP；
- 禁用空口令、禁用 X11 转发、限制可登录用户/组；
- 走堡垒机/VPN，开启 MFA。

### 3. 服务与端口
- `systemctl disable` 关闭不需要的服务；
- 只开放必要端口，用防火墙（firewalld/iptables）限制；
- 关闭 Telnet、FTP 明文服务，改用 SSH/SFTP。

### 4. 权限与文件
- 关键文件权限收敛（`/etc/passwd`、`/etc/shadow`、`/etc/sudoers`）；
- 定期检查异常 SUID/SGID：`find / -perm -4000`；
- 敏感目录与服务脚本不可被普通用户写；
- 配置文件中的口令不落地明文。

### 5. 日志与审计
- 开启 rsyslog、auditd，认证/提权/关键操作可审计；
- 日志集中到日志服务器，防篡改，按规留存；
- 时间同步（NTP/chrony）。

### 6. 其他
- 及时更新内核与软件补丁；
- 部署 HIDS（如 Wazuh、青藤等）、文件完整性监控（AIDE）；
- 防火墙、SELinux/AppArmor 按需启用；
- 数据备份并验证可恢复；
- 关闭危险的 cron 或未知计划任务。

## 三、Windows 加固基线

### 1. 账号与口令
- 重命名/禁用 Administrator、Guest 禁用；
- 强密码策略（本地安全策略/域 GPO）、账户锁定阈值；
- 最小化本地管理员组成员，分离日常与管理账号；
- 特权账户启用多因素。

### 2. 远程访问
- RDP 不暴露公网，改默认端口、限制来源 IP（仅缓解，配合 VPN/堡垒机）；
- 开启网络级身份验证（NLA）；
- 关闭不必要的 SMB（尤其 445）对外，禁用 SMBv1。

### 3. 补丁与服务
- 开启 Windows Update、及时打补丁；
- 关闭不必要服务与端口（`services.msc`、防火墙）；
- 最小化角色安装（IIS 等按需）。

### 4. 权限与审计
- NTFS 最小权限、共享权限收敛；
- 开启审核策略（登录、账户管理、特权使用、策略更改）；
- 事件日志集中、增大容量、按规留存。

### 5. 防护
- 开启 Windows Defender/EDR、BitLocker（按需）；
- 防火墙默认拒绝入站；
- 启用 UAC；
- 注册表与计划任务、启动项定期基线检查。

## 四、中间件/应用主机附加
- 应用低权限运行（不用 root/管理员跑业务）；
- 管理后台、数据库、中间件控制台不暴露公网、改默认口令；
- 容器主机加固、镜像最小化、能力裁剪（cap-drop）、不挂载 docker.sock。

## 五、加固验证与产出
- 用核查表/脚本（CIS Benchmark、厂商基线）逐项检查；
- 漏洞扫描 + 配置核查 + 抽样验证；
- 输出加固前/后对比、未整改项与风险接受、复测结果。

## 六、与岗位/项目关联
- 安全运维、等保测评、安全服务交付都要求会按基线加固主机；
- SecAgent 修复的路径穿越、鉴权、CORS、会话、异常处理属于"应用层加固"，与本文"系统层加固"互补，面试时可串成"系统 + 应用 + 数据"的完整加固体系。
