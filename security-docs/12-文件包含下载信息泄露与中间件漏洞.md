# 文件包含、文件下载、信息泄露与中间件漏洞

## 一、文件包含（LFI/RFI，CWE-98）
- 原理：动态包含文件时把用户输入拼进包含路径，如 PHP `include($_GET['f'])`。
- 危害：本地文件包含（LFI）读取/执行敏感文件、结合日志/上传触发 RCE；远程文件包含（RFI）加载远程脚本。
- 防御：白名单包含项、映射 ID 而非传入文件名、关闭远程包含（`allow_url_include=Off`）、不把用户输入拼入路径。

## 二、任意文件下载（CWE-552）
- 原理：下载/导出接口用用户输入拼路径，如 `?file=../../../etc/passwd`。
- 与路径穿越同源（CWE-22），结果是读取源码、配置、密钥、系统文件。
- 防御：规范化路径并校验在白名单目录内、白名单文件、以 ID 映射、禁止直接回显原始路径。

## 三、信息泄露（CWE-200）
- 常见点：
  - 报错信息泄露堆栈、框架版本、SQL、物理路径；
  - 目录列举（Directory Listing）、备份文件（`.bak/.zip/.sql`）、`.git/.svn`、`WEB-INF/web.xml`；
  - 接口返回过多字段（手机号、身份证、内部 ID）、Swagger/Actuator 暴露；
  - 前端 JS、注释、sourcemap 中含接口、密钥。
- 防御：统一错误处理、关闭调试与目录列举、清理备份/版本库、接口最小化字段、敏感端点加鉴权。

## 四、业务逻辑漏洞
- 原理：利用设计/流程缺陷，无法用注入特征识别。
- 典型：
  - 支付/数量/金额篡改（负数、改价、并发重复提交）；
  - 验证码绕过（前端校验、可复用、不过期）；
  - 密码找回缺陷（任意重置、凭证可预测）；
  - 越权（见越权专题）、水平/垂直绕过；
  - 多步骤流程跳步、状态依赖错误。
- 防御：服务端做完整状态机校验、金额由服务端计算、验证码一次性且服务端校验、关键操作幂等。

## 五、中间件/组件漏洞
- 常见：
  - Tomcat：弱口令 manager、AJP Ghostcat（CVE-2020-1938）；
  - Nginx/Apache：错误配置、解析漏洞、目录穿越；
  - Redis：未授权访问（写计划任务/SSH 公钥/Webshell，是挖矿常见入口）；
  - WebLogic：反序列化、SSRF、控制台弱口令；
  - Shiro/Struts/Fastjson：反序列化 RCE；
  - 框架历史 RCE（如 S2 系列、Spring 系列）。
- 防御：最小化安装、改默认口令、禁止暴露管理面、及时升级、关注 CVE、WAF 临时缓解、SCA 扫描依赖。

## 六、会话与认证缺陷
- 固定会话（Session Fixation）、可预测 Session ID、JWT（弱密钥、none 算法、不过期）；
- 防御：登录后重新签发 Session、强随机 ID、服务端校验、JWT 强密钥并校验算法、合理过期。

## 七、研判与审计要点
- 日志中出现 `..%2f`、`/etc/passwd`、`.git`、`web.xml`、`/actuator`、对后台与管理端口的探测，结合目录扫描告警，判断为信息收集/敏感文件探测；
- 代码审计从"用户输入 → 文件/包含/路径/组件配置"回溯；
- 组件漏洞先看版本指纹，再匹配 CVE 并验证。
