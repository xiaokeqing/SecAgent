# OWASP Top 10 与常见 Web 漏洞概览（安全知识库）

> 适用范围：授权范围内的安全防护、教学与应急响应。本文仅用于防御与理解攻击原理。

## 一、什么是 OWASP Top 10

OWASP（开放式 Web 应用安全项目）每隔数年发布一次 Top 10，列出对 Web 应用危害最普遍、最严重的十类风险。它是安全开发、代码审计、渗透测试和安全运营的通用语言。

## 二、2021 版 Top 10 速览

| 编号 | 名称 | 典型表现 |
|------|------|----------|
| A01 | 失效的访问控制（Broken Access Control） | 越权访问、目录穿越、未授权接口、IDOR |
| A02 | 加密机制失效（Cryptographic Failures） | 明文传输、弱哈希、硬编码密钥、敏感数据泄露 |
| A03 | 注入（Injection） | SQL 注入、命令注入、LDAP 注入、表达式注入 |
| A04 | 不安全设计（Insecure Design） | 缺少限流、缺少防自动化、业务逻辑缺陷 |
| A05 | 安全配置错误（Security Misconfiguration） | 默认口令、CORS 全开放、错误信息泄露堆栈、调试接口暴露 |
| A06 | 自带易受攻击的组件（Vulnerable Components） | 老旧框架/中间件存在已知 CVE |
| A07 | 身份识别和认证失效（Authentication Failures） | 弱口令、爆破、会话固定、凭据填充 |
| A08 | 软件与数据完整性失效（Integrity Failures） | 不安全的反序列化、不可信来源的更新/CI |
| A09 | 安全日志与监控失效（Logging & Monitoring Failures） | 攻击发生后无日志、无告警、无法溯源 |
| A10 | 服务端请求伪造（SSRF） | 服务端按用户输入发起请求，被利用访问内网/元数据 |

## 三、与本项目告警对应的漏洞类型

- **SSH 暴力破解**：对应 A07 认证失效。攻击者通过字典反复尝试登录，成功后可直接获得主机权限。
- **SQL 注入**：对应 A03 注入。攻击者把恶意 SQL 拼进查询，可读取/篡改数据库、绕过认证。
- **Webshell 上传**：通常由 A03（命令注入）、A01（访问控制）、文件上传校验缺陷共同导致，是 Web 入侵的常见落点。
- **目录扫描**：攻击侦察阶段行为，对应 A05/A09，常用于发现后台、备份文件、配置文件（如 .env、/actuator）。

## 四、通用处置原则（事件响应四步）

1. **止损（Contain）**：封禁来源 IP、下线或隔离受影响主机、暂停高危服务。
2. **根除（Eradicate）**：清除 Webshell、后门、计划任务、异常账号，修补漏洞。
3. **恢复（Recover）**：从可信备份恢复，验证业务正常，加强监控。
4. **复盘（Lessons Learned）**：补检测规则、加固基线、完善日志与告警。

## 五、防御总原则

- 所有外部输入都不可信：白名单校验、参数化、最小权限。
- 安全要左移到设计与编码阶段，并以日志监控闭环（A09）。
- 深度防御：网络层（WAF/防火墙）、主机层（HIDS/最小化）、应用层（校验/鉴权）、数据层（加密/备份）多层防护。
