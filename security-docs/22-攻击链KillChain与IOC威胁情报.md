# 攻击链（Kill Chain）与 IOC 威胁情报

## 一、攻击链（Cyber Kill Chain，七阶段）
1. **侦察 Reconnaissance**：扫描、指纹识别、子域名、信息收集。
2. **武器化 Weaponization**：制作后门、Exploit、钓鱼文档。
3. **投递 Delivery**：上传 Webshell、钓鱼邮件、水坑、U 盘。
4. **利用 Exploitation**：触发漏洞（SQL 注入、命令注入、RCE）。
5. **安装 Installation**：植入后门、持久化（计划任务、服务）。
6. **命令控制 Command & Control（C2）**：建立外连，受控于攻击者。
7. **行动 Actions on Objectives**：窃取数据、横向移动、勒索、挖矿。

## 二、ATT&CK 视角
MITRE ATT&CK 把攻击行为组织为战术与技术矩阵，例如：
- 初始访问（钓鱼、利用外网应用、有效账号）；
- 执行（命令与脚本、Web Shell）；
- 持久化（计划任务、服务、注册表）；
- 权限提升、防御绕过、凭据访问；
- 发现、横向移动、收集、命令与控制、数据渗出。

## 三、如何还原攻击链
研判时把告警与日志按时间串成链：
- **侦察**：目录扫描、端口扫描（大量 404）；
- **利用**：SQL 注入、命令注入、上传 Webshell；
- **建立权限**：SSH 爆破成功、Webshell 命令执行；
- **持久化/横向**：加账号、计划任务、登录其他主机；
- **外连**：防火墙出现到 C2/矿池的连接。
单点日志不足以定性，必须多源印证。

## 四、IOC（Indicator of Compromise，失陷指标）
- **网络 IOC**：攻击源 IP、C2 IP/域名、URL、异常端口、DNS 请求；
- **主机 IOC**：恶意文件路径、文件哈希（MD5/SHA256）、注册表项、计划任务、进程名；
- **账号 IOC**：异常账号、登录 IP、时间；
- 示例：`103.146.184.77`（SSH 爆破源）、C2 `:4444`、Webshell 文件。

## 五、威胁情报
- 平台：微步在线、Virustotal、AbuseIPDB、AlienVault OTX；
- 用途：查 IP/域名/哈希的信誉、归属、是否已知 C2/矿池；
- 处置：封禁 IOC、加入黑名单、在全网检测是否还有其他主机命中同一情报。

## 六、研判报告示例结构
1. 事件概述与结论；
2. 活跃告警清单；
3. 日志证据（多源、带时间与 IP）；
4. 攻击链还原（Kill Chain 阶段）；
5. IOC 列表；
6. 影响范围与等级；
7. 处置与加固建议。

## 七、与项目关联
多 Agent 研判的最终产物即上述《安全事件研判报告》：Planner 规划，Executor 调用告警/日志/知识库工具完成证据关联，Supervisor 汇总攻击链、IOC 与处置建议，把人工研判过程自动化。
